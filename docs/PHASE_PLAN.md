# Development Phases

1. Foundation: frontend, backend and local health checks.
2. Database and security: Supabase schema, RLS and storage policies.
3. Identity: registration, login, recruiter ID validation and admin access.
4. Submissions: secure uploads, collections and review workflow.
5. Membership: configurable plans, Paystack checkout and verification.
6. Acquisitions and rights: offers, agreements and acquisition payments.
7. Portfolio and publishing: gallery, featured artists and collections.
8. Ledger and withdrawals: earnings, audited adjustments and payouts.
9. Operations: notifications, reporting, security testing and deployment.

Test each phase before moving to the next.
